XLGoBench: Detecting Cross-lingual Skill Gaps
with Algorithmic Tasks

Purvam Jain1, Preethi Jyothi2, Vihari Piratla1, Suvrat Raju3

1Google DeepMind    2IIT Bombay    3ICTS-TIFR

EMNLP 2026

Paper (arXiv) PDF

Overview of XLGoBench tasks. Five synthetic algorithmic tasks — Sequential Linear Transforms (SLT), Discrete State Automaton (DSA), Probabilistic-DSA (Pr-DSA), Graph Shortest Path (Graph SP), and Tournament Ranking (T-Rank) — each with scalable complexity and objective correctness criteria.

Overview

Abstract

We introduce a set of synthetic algorithmic tasks to detect cross-lingual gaps in the abilities of large language models. Our benchmark is commensurate across languages, since it requires models to perform the same underlying task in different languages; scalable, since each task can be generated at varying levels of complexity allowing it to be adapted to models with different capabilities; quantifiable, since every task admits an objective notion of correctness; and transparent, since tasks are generated from simple templates that can be readily audited for translation errors. Because our benchmark focuses on algorithmic tasks, differential performance is a sufficient — but not necessary — indicator of cross-lingual gaps. Nevertheless, we show through extensive experiments that our benchmark exposes persistent cross-lingual gaps in multiple state-of-the-art models.

Benchmark

Algorithmic Tasks

01

Sequential Linear Transforms (SLT)

A merchant visits cities in sequence, each applying a linear transform to their capital. The events are shuffled, and the model must reconstruct the chronological order and compute the final wealth. Tests sequential reasoning and arithmetic over ordered steps.

02

Discrete State Automaton (DSA)

Navigate a building with rooms connected by keyed doors. Given a sequence of keys, determine the final room. Tests the ability to track state transitions through a deterministic automaton.

03

Probabilistic-DSA (Pr-DSA)

Extension of DSA where each key leads to one of two rooms with specified probabilities. The model must list the most probable final rooms, requiring probabilistic reasoning over state transitions.

04

Graph Shortest Path (Graph SP)

Given a social network described by relationships (friends, coworkers, classmates, etc.), find the shortest chain connecting two people. Tests graph traversal and shortest-path reasoning.

05

Tournament Ranking (T-Rank)

Given shuffled pairwise match results with transitive redundancy, rank all players from strongest to weakest. Tests topological sorting and consistent ordering from partial information.

Findings

Key Results

Through extensive experiments across multiple state-of-the-art LLMs, we show that XLGoBench exposes persistent cross-lingual gaps even in frontier models. Performance consistently degrades when tasks are presented in non-English languages, despite the underlying algorithmic reasoning being language-independent. The scalable complexity of our tasks allows fine-grained analysis of where and how these gaps emerge as task difficulty increases.
